# Thư mục Ý tưởng Thô (Raw Notes Inbox)

Nơi bạn thả bất kỳ ý tưởng, mẹo lượm lặt, hoặc câu prompt thô nào vào đây mỗi ngày.

---

### Cách sử dụng:
1. Tạo 1 file mới bất kỳ trong thư mục này, ví dụ: `meo-excel-ngam.md` hoặc `chatgpt-trick.txt`.
2. Gõ nội dung thô tùy ý (không cần format đẹp, có thể là copy từ comment YouTube, Facebook, Reddit hoặc ghi chú nhanh).
3. Sau đó chỉ cần nói với Antigravity:
   > *"Đăng bài prompt trong raw_notes cho tao"* hoặc *"Xử lý file meo-excel-ngam.md"*.
4. Hệ thống Multi-Agent sẽ tự động:
   - Kích hoạt `4-content-editor`: Chuẩn hóa, tách biến số `[...]`, tạo ví dụ giả lập Before/After.
   - Kích hoạt `5-content-publisher`: Đưa vào cơ sở dữ liệu `src/data/prompts/` và dọn dẹp file nháp.
   - Kích hoạt `3-qa-verifier`: Kiểm tra build và xuất bản lên web.
